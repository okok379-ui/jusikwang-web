화면으로 보는 연습게임 사용법

20% 이상 오른 관심종목의 다음 거래일 차트를 1분씩 재생하면서, 직접 사고팔아 보는 연습게임입니다. 아래 순서대로 따라 하면 5분 안에 첫 판을 할 수 있어요.

  • 1화면 구성
  • 2종목 고르기
  • 3재생·조작
  • 4직접 매매(수동)
  • 5규칙 매매(자동)
  • 6익절 완료
  • 7마무리·복기
  • 8차트 도구
  • 9핸드폰

1화면 구성

왼쪽은 차트, 오른쪽은 시세·내 계좌·주문, 아래는 조작 버튼이에요.

  1. 종목·날짜 — 종목명과 기준봉 날짜(검색된 날) → 매매일. 매매는 항상 기준봉 다음 거래일에 해요.
  2. 1분봉 — 가장 촘촘한 차트. 보라색 선은 10이평, 주황 점선은 전일 종가.
  3. 3분봉 — 흐름을 보기 좋은 차트. 내 매수(▲)·매도(▼) 위치와 이유가 표시돼요.
  4. 일봉 — 최근 한 달 흐름과 날짜. 맨 오른쪽 주황 날짜가 오늘(매매일) 봉이에요.
  5. 현재가 — 전일 대비·시가 대비 등락률과 현재 시각.
  6. 내 계좌 — 평단가·보유수량·평가손익·실현손익·현금·총자산·현재 수익률(평단 대비).
  7. 주문 — 매수금액을 고르고 매수 추가매수 절반 매도 전량 매도.
  8. 자동 규칙 설정 — 분할 매도 목표, 그 아래 분할매수 설정(스크롤).
  9. 조작 버튼 — 재생, 1분씩 넘기기, 매매 마무리, 종목 선택 등.
시작 자금은 가상 1,000만 원이에요. 실제 돈은 전혀 들지 않아요.

2종목 고르기

아래 조작 버튼의 📅 종목 선택을 누르면 이 창이 열려요.

  1. 날짜 = 기준봉(검색된) 날짜예요. 매매는 그 다음 거래일 차트로 해요.
  2. 종목명·코드와 날짜를 넣을 수 있어요. 비워두면 전체 목록이 보여요.
  3. ▶ 입력한 종목·날짜로 매매 시작 — 입력한 종목으로 바로 시작.
  4. 🎲 랜덤 종목으로 연습 — 아무 종목이나 골라 줘요. 감 잡기에 좋아요.
  5. ⚙️ 키움 API 설정 — 목록에 없는 종목·날짜를 키움에서 받아올 때만 필요해요(선택).
  6. 목록 — 기준봉 날짜별로 묶여 있고 → 매매일이 함께 보여요. 종목을 누르면 바로 시작!
2026년 1월~11월에 +20% 이상 오른 실제 종목 500여 개가 들어 있어요.

3재생·조작 버튼

차트는 장 시작부터 1분씩 흘러가요. 원하는 속도로 재생하거나 한 칸씩 넘겨 보세요.

  1. ▶ 시작 / 계속 — 재생·일시정지. 키보드 Space.
  2. 다음 1분봉 ▸ — 한 칸(1분)씩 넘겨요. 신중하게 볼 때.
  3. 🏁 매매 마무리 — 이번 판을 끝내고 결과를 봐요.
  4. 📅 종목 선택 — 다른 종목으로 바꿔요.
  5. 📒 거래내역 — 지금까지 사고판 기록(날짜·시각·가격·이유).
  6. ✏️ 지지저항선 긋기 / 수평선 / 추세선 / 선 지우기 — 차트에 직접 선 긋기.
  7. 수동 자동 — 내가 직접 매매할지, 규칙대로 자동 매매할지(4·5번 참고).
  8. 단축키 — B 매수, S 전량 매도.
  9. ➖ 100% ➕ 확대·축소, ◀ ▶ 이전/다음 시간 보기.
  10. 0.5× 1× 2× 4× — 재생 속도.
장이 끝나도 멈추지 않아요. 보유 수량·평단을 그대로 들고 다음 거래일 차트로 이어서 진행돼요. 그만하려면 🏁 매매 마무리.

4직접 매매하기 (수동 모드)

기본은 수동이에요. 내가 누른 주문만 체결돼요.

① 매수금액 고르기→② 매수→③ 수익률 보기→④ 절반/전량 매도
  1. 매수금액 — 100만 300만 500만 최대 중 고르거나 직접 입력.
  2. 매수 또는 추가매수 — 현재가로 바로 체결돼요. 차트에 ▲매수 표시.
  3. 현재 수익률은 평단가 대비예요. 빨강 = 수익, 파랑 = 손실.
  4. 절반 매도 전량 매도 — 차트에 ▼매도 표시, 실현손익에 반영.
눌림을 기다렸다가 사고, 정해 둔 목표에서 나눠 파는 연습을 해 보세요. 급등 직후 따라 사면 결과창에서 지적해 줘요.

5규칙대로 자동 매매 (자동 모드)

규칙을 정해 두고 자동을 누르면 프로그램이 대신 사고팔아요. 내 규칙이 통하는지 검증할 때 좋아요.

분할 매도 목표
분할매수 · 1차 자동 진입
규칙하는 일
1차 자동 진입매매일 장 시작에 1회 매수금(기본 100만 원)으로 1차 매수. 전량 매도되면 1분 뒤 다시 1차 매수.
분할매수 2~9차최초 매수가(평단 아님) 대비 −3%, −6%, … −24%마다 같은 금액씩 추가 매수.
분할 매도 1~3차평단 대비 목표 수익률에 닿으면 그때 남은 잔량의 비중(%)만큼 매도. 100% = 전량.
리셋어떤 매수든 체결되면 매도 목표는 처음(1차)부터 다시 적용돼요.
① '사용' 체크→② 숫자 입력→③ 저장 꼭 누르기→④ 아래 자동 선택→⑤ ▶ 시작
자동 모드 예시 — 3분봉에 분할매수 2차(−3%), 3차(−6%)가 체결된 모습. 오른쪽 위에 '🤖 자동 매매 중' 표시.
저장을 누르지 않으면 바뀐 숫자가 적용되지 않아요. 수동 모드에서는 규칙이 동작하지 않아요.

6익절 완료 — 계속할까, 마무리할까

보유 종목이 전량 수익으로 팔리면 재생이 멈추고 물어봐요.

▶ 계속 진행그대로 이어서 매매해요(자동 모드면 1분 뒤 1차 재진입).
🏁 매매 마무리여기서 끝내고 결과를 봐요.
📈 차트로 돌아가기창만 닫고 멈춘 차트에서 방금 매매를 복기해요.

차트로 돌아가면 화면 맨 위에 선택 바가 떠 있어요. 다 보고 고르면 돼요.

7매매 마무리와 복기

🏁 매매 마무리를 누르면 결과 카드가 나와요.

  1. 등급과 수익률 — 이번 판의 내 수익률과 한 줄 평가.
  2. 교과서 매매와 비교 — 원칙대로 했으면 몇 %였는지.
  3. 🔍 차트로 복기하기 — 하루 전체 차트에서 내 매수·매도 위치와 마무리 이후 흐름까지 확인.
  4. 📖 교과서 매매 보기 — 원칙대로라면 어디서 사고팔았을지 차트에 표시.
  5. 같은 종목 재도전 — 같은 종목·같은 날을 처음부터 다시. 새 종목 선택 ▸ — 다른 종목으로.
복기 화면 — 회색 점선 🏁 마무리 이후의 흐름까지 보여요. 휠로 확대해서 타점을 자세히 보세요. 아래 ↩ 결과로 돌아가기로 결과 카드로 돌아가요.

📒 거래내역에서는 언제·얼마에·왜 샀고 팔았는지 한 표로 볼 수 있어요.

8차트 도구

눌림·지지 자리를 찾는 연습을 돕는 보조 기능이에요. 매매는 하지 않고 표시만 해요.

📈 구간 표시3분봉 10이평 기울기로 배경색 표시. 분홍 = 상승, 청록 = 하락, 회색 = 횡보. 바뀌는 순간 ▲매수/▼매도 표시.
🤖 자동 지지저항고점·저점이 반복된 가격대에 지지·저항선을 자동으로 그려요.
✏️ 선 긋기수평선은 한 번, 추세선은 두 점을 눌러 직접 그어요. 선 지우기로 전체 삭제.
확대·축소차트 위에서 마우스 휠 또는 ➖ ➕. 100%로 원래대로.
이전 시간 보기차트를 오른쪽으로 끌거나 ◀ 버튼(또는 Shift+휠). 돌아올 땐 ⏭ 최신.

9핸드폰에서

핸드폰에서도 PC처럼 왼쪽 차트, 오른쪽 시세·내 계좌·주문이 한 화면에 보여요.

  1. 오른쪽 칸은 위아래로 스크롤하면 분할 매도·분할매수 설정이 나와요.
  2. 아래 조작 버튼 줄은 옆으로 밀면 나머지 버튼이 나와요.
  3. 차트를 손가락으로 오른쪽으로 밀면 이전 시간을 볼 수 있어요.
  4. 화면이 좁게 느껴지면 핸드폰을 가로로 돌려 보세요.
궁금한 점은 오른쪽 아래 💬 오픈채팅방 입장(카카오톡)으로 들어와 편하게 물어보세요.
