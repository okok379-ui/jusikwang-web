주식한판 사용자 메뉴얼

오늘도 주식게임 한 판, 실력은 한 단계 업!

전일 상한가 종목의 눌림목 단타를 실제 과거 데이터로 재생하며 연습하는 모의 매매 게임입니다. 가상의 1,000만원으로 매수·매도 타이밍을 훈련하세요. (실제 투자가 아니며 수익을 보장하지 않습니다.)

1주식한판이란

차트를 1분봉 단위로 재생하면서, 실제처럼 매수·매도 버튼을 눌러 단타 매매를 연습하는 게임입니다. 미래 구간은 가려져 있고 시간이 흐르듯 캔들이 하나씩 그려지므로, 결과를 모른 채 실전 감각으로 판단하게 됩니다.

  • 실데이터 모드 — 종목명·날짜를 지정하면 키움 과거 데이터로 그 종목을 그대로 재생합니다.
  • 랜덤 연습 모드 — 가상으로 생성된 상한가 눌림 패턴으로 가볍게 연습합니다.
  • 1분봉·3분봉·일봉을 함께 보며, 분할매수·분할 매도·자동 진입까지 자동 규칙으로 돌려볼 수 있습니다.

2시작하기

종목 선택으로 시작

  1. 툴바의 📅 종목 선택을 누릅니다.
  2. 종목명을 입력하면 자동완성 목록에서 코드까지 찾아줍니다. 같은 이름이 여럿이면 아래 목록에서 고르세요.
  3. 달력에서 날짜를 선택합니다.
  4. 매매 시작을 누르면 그 종목·날짜가 로드됩니다.

가볍게 해보려면 🎲 랜덤 종목으로 연습을 눌러 가상 케이스로 시작할 수 있습니다.

키움 API 키 설정 (실데이터용)

실제 종목 데이터는 키움증권 REST API로 직접 받아옵니다. 한 번만 키를 등록하면 됩니다.

  1. 종목 선택 창 또는 툴바의 ⚙️ 키움 API 설정을 엽니다.
  2. 앱키(App Key)와 시크릿키(Secret Key)를 입력하고 저장합니다.
보안 — 입력한 키는 내 브라우저에만 저장되고(localStorage) 서버·외부로 전송되지 않습니다. 공용 PC에서는 사용 후 설정에서 지워 주세요.

3화면 구성

상단 정보

  • 종목명·코드·시총, 현재가, 전일비(전일 종가 대비)·시가비(당일 시가 대비).
  • 평단가 보유수량 보유금액 평가손익 실현손익 현금 총자산 현재 수익률.

차트 3종

  • 1분봉 / 3분봉 / 일봉이 세로로 함께 표시됩니다. 눌림 타점은 1·3분봉으로 보고, 추세·위치는 일봉으로 확인합니다.
  • 각 패널 위에서 마우스 휠을 굴리면 그 패널만 따로 확대·축소됩니다.
  • 이동평균선 4·15·20·120선을 사용합니다.

우측 패널

매매 주문, 분할 매도 목표, 분할매수 설정이 모여 있습니다. 내용이 길면 패널 안에서 스크롤됩니다.

4재생 컨트롤

  • ▶ 시작 / 계속 — 차트 재생/일시정지. Space로도 됩니다.
  • 다음 1분봉 ▸ — 한 봉씩 수동으로 넘깁니다. → 키.
  • 0.5× 1× 2× 4× — 재생 속도.
  • 🏁 매매 마무리 — 현재가로 전량 청산하고 결과를 봅니다. 멈추고 싶을 때는 이 버튼만 누르면 됩니다.
연속 진행 — 하루가 끝나도 멈추지 않고 다음 거래일로 자동으로 이어서 재생됩니다. 전날 봉은 그대로 두고 다음날 봉이 뒤에 붙으며, 보유·평단·현금·그어둔 선도 모두 유지됩니다.

5매매하기

  • 매수금액 입력 또는 100만 300만 500만 최대 버튼으로 금액을 정합니다.
  • 매수 B — 매수(B). 추가매수 — 같은 금액으로 더 담기.
  • 절반 매도 / 전량 매도 S — 보유분 매도(S는 전량).
  • 수동 / 자동 — 수동은 내가 직접 매매합니다(자동 규칙은 동작하지 않음). 자동은 아래 분할 매도 목표·분할 매수·1차 자동 진입 규칙(체크한 것)대로 프로그램이 매매합니다. 자동 모드에서도 직접 주문 버튼은 쓸 수 있습니다.

6분할 매도 목표

우측 🎯 분할 매도 목표 패널에서 1·2·3차 목표 수익률(%)과 매도 비중(%)을 정하고 사용을 켭니다.

  • 평단 대비 수익률이 목표에 닿으면 자동으로 그 비중만큼 매도합니다. (자동 모드)
  • 비중은 그때 남은 잔량 기준입니다. 예: 1차 50% → 절반 매도, 2차 30% → 남은 것의 30%. 전량으로 끝내려면 마지막 차수를 100%로.
  • 매수(재매수·추가매수)를 하면 새 평단 기준으로 1·2·3차가 다시 무장됩니다.

7분할매수·자동 재진입

우측 🔻 분할매수 패널입니다.

  • 1회 매수금을 정하면 모든 차수가 그 금액으로 균등 매수합니다(예: 100만원씩).
  • 최초 매수가 기준으로 각 차수의 하락률(%)에 닿을 때마다 자동 매수합니다. 2차~9차까지, 기본 −3%·−6%·−9%…
  • 1차는 직접 매수하거나 아래 1차 자동 진입으로 시작합니다. 비운 차수는 건너뜁니다.
  • 1차 자동 진입을 켜면 진행일(기준봉 다음날) 장 시작에 바로 1회 매수금으로 삽니다. 전량 매도하면 1분 뒤(다음 1분봉)에 바로 1차로 다시 진입해 사이클이 이어집니다.
  • 보유가 전량 익절되면 재생이 멈추고 계속 진행 / 매매 마무리를 묻습니다.
분할 매수·매도·재진입은 자동 모드에서만 작동합니다. 수동 모드에서는 내가 누른 주문만 체결됩니다.

8차트 도구

  • ✏️ 지지저항선 긋기 — 차트에 마우스로 연필처럼 자유롭게 선을 그립니다.
  • ─ 수평선 — 수평 지지·저항선.
  • ╱ 추세선 — 저점·저점을 잇는 추세선.
  • 선 지우기 — 그은 선을 모두 지웁니다.
  • 📈 구간 표시 — 상승·하락·지지 구간을 배경색으로 표시.
  • 🤖 자동 지지저항 — 고점·저점이 반복된 가격대를 자동으로 선으로 표시.

그어둔 선은 다음 거래일로 연속 진행해도 그대로 유지됩니다.

9거래내역

툴바 📒 거래내역을 누르면 이번 세션의 모든 매매가 표로 나옵니다.

  • 구분·날짜·시각·가격·수량·금액·실현손익·이유를 보여줍니다.
  • 매도마다 그 거래의 실현손익을 평단 기준으로 계산해 +/−로 표시합니다.
  • 이유에는 직접 매수/추가매수, 분할매수 N차, 재진입, 분할매도 목표 도달, 자동 손절·익절, 청산 등이 기록됩니다.
  • 상단에 매수·매도 횟수와 총 실현손익 요약이 나옵니다.

10지표 읽는 법

  • 현재 수익률 — 지금 보유 포지션의 평단 대비 수익률입니다(투자원금 기준). 예: 100만원어치에 4만원 수익이면 +4%.
  • 평가손익 — 보유분의 미실현 손익. 실현손익 — 매도로 확정된 손익(수수료 반영).
  • 총자산 — 현금 + 보유 평가금액. 시드 1,000만원에서 출발합니다.
거래내역의 실현손익은 평단 기준 계산이라, 수수료까지 반영된 상단 ‘실현손익’과 몇 원 차이가 날 수 있습니다.

11자주 묻는 질문

연속 진행 중 갑자기 멈춰요.

키움 1분봉 데이터는 최근 일정 기간만 제공됩니다. 데이터가 있는 가장 최근 거래일에 도달하거나, 중간에 분봉이 없는 날을 만나면 더 진행할 수 없어 그 자리에서 멈춥니다(보유·평단은 그대로 유지). 청산되지 않으니 안심하세요. 마감하려면 🏁 매매 마무리를 누르면 됩니다.

랜덤 종목의 시총이 실제와 달라요.

랜덤(합성) 케이스는 가상 수치입니다. 실제 시총은 종목 선택(키움 직접조회)으로 플레이할 때 정확히 표시됩니다.

입력한 API 키는 안전한가요?

키는 내 브라우저에만 저장되며 서버로 전송되지 않습니다. 공용 PC에서는 사용 후 지워 주세요.

이론(매매 원칙)도 배우고 싶어요.

상단 📚 지지저항 배우기 또는 홈의 강의에서 기준봉 눌림 단타 매수·분할·손절·매도 원칙을 단계별로 익힐 수 있습니다.

가상의 종목·가격 데이터로 매매 원리를 연습하는 교육용 게임입니다. 실제 투자 판단·수익을 보장하지 않습니다.
